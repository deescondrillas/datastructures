Each folder in this repository corresponds to an activity. In each case, the final stage of the activity uses a list of logs (of size 2¹⁸) to emulate the analysis of login sessions within a network.

  - **Act1** – Use of different sorting and searching algorithms within the logbook
  - **Act2** – Implementation of linked lists for storing and operating on logs
  - **Act3** – Implementation of binary search trees and AVL rotations for storing and operating on logs
  - **Act4** – Implementation of graphs to simulate network connections
