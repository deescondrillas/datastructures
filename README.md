Each folder in this repository corresponds to an activity. In each case, the final stage of the activity uses a list of logs (of size 2^18) to emulate the analysis of login sessions within a network.
  \n\tAct1 – Use of different sorting and searching algorithms within the logbook
  \n\tAct2 – Implementation of linked lists for storing and operating on logs
  \n\tAct3 – Implementation of binary search trees and AVL rotations for storing and operating on logs
  \n\tAct4 – Implementation of graphs to simulate network connections
